# Utils

Internal utility functions and types shared across `@chronus-dev` packages.

## Installation

```sh
npm install @chronus-dev/utils
```

## Usage

```ts
import { isString } from '@chronus-dev/utils'

isString('foo') // => true
isString(123) // => false
```

Read the [docs](https://utils.chronus.dev) to learn more.
